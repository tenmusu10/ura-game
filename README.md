# おぼろ団地と303号室

昼はさびれた団地を切り盛りし、夜は街の"裏側"にもぐる、団地経営＋ダンジョン探索のドット絵ゲームの企画リポジトリです。
いまは実装前で、世界観の決定事項と、素材を生成AIで作るためのプロンプトを置いています。

- エンジン：Godot 4（2D、320×180）
- 画像生成：Gemini／音楽：Suno／効果音・映像：ツール未定

## フォルダ構成

| フォルダ | 中身 |
|---|---|
| `prompts/` | 世界観バイブル（`00_world_bible.md`＝すべての正本）、物語、住人、画像・音・映像のプロンプト、検討メモ（`ideas_*.md`） |
| `story/` | 物語の説明図（団地と303号室など） |
| `system/` | 戦闘・数値バランスのシミュレーション |
| `images/` | システムの説明図など |
| `preview/` | ドット絵の試作 |

## ルール

- 設定・用語・色・解像度は `prompts/00_world_bible.md` が正です。変えるときは、まずバイブルを直してから各ファイルに反映します。
- `ideas_*.md` は検討の経過です。決定内容はバイブルと各決定版ファイルを見てください。
