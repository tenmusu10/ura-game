## 1. コンセプト（ひとこと）

**「昼はさびれた団地を切り盛りし、夜は街の"裏側"にもぐる」**
地方都市の真下に広がる迷宮で、忘れられたものと出会い、住人として団地に迎え入れ、部屋と並びを整えて強くなっていく、団地経営＋ダンジョン探索ゲーム。

## 2. 舞台

| 項目 | 設定 |

| 街 | 海と山にはさまれた地方都市「**灯野市（ひのし）**」。商店街、学校、古い団地、港。少しさびれているが温かい。 |
| 時代 | 現代日本。ただしスマホより公衆電話や駄菓子屋が目立つ、少し懐かしい空気。 |

| ハザマのしくみ | 街で忘れられたもの（落とし物、捨てられた夢、言えなかった言葉）が流れ着いて形になった世界。階層ごとに街の一角を裏返したような見た目をしている。 |
| 敵 | 「**カゲ**」。忘れられたものが寂しさで暴れている存在。倒すと「**ヒノカケラ**」（ハザマでの通貨・成長素材）を落とす。 |

### 物語の軸：ドアだけの303号室

- **303号室には、ドアしかない。** 3階の302と304のあいだの壁に、303の表札とドアだけがついている。開けてもすぐ壁で、部屋はない。
- それなのに、図面・郵便・市の書類には303がある。フミオの届かなかった手紙も「灯野第三団地 303号室」に宛てられている。
- 住人はみんな「303には昔から部屋がない」と知っているが、理由はだれも知らない。ドアや壁を壊しても、向こうはただの外で部屋はない。
- 部屋そのものは、ハザマ側の団地（カゲモリの団地）にだけある。
- 管理人室のサカキの日誌には「303の約束を守れなかった」とある。
- **24部屋の修繕がすべて終わる（全開放）** と表と裏の団地がつながり、ドアの向こうに303の部屋が現れて **終章** が始まる。条件は修繕で、入居の人数ではない。
- 303は5×5の **ちょうど真ん中** なので、現れた瞬間に縦・横・斜め2本の **4ラインが一気につながる**。
- 図：[../story/danchi_303_map.png](../story/danchi_303_map.png)
- 物語の決定版は **20_story.md**（主人公・章ごとのストーリーはこちらが正）。

#### 303の正体
- 303は、初代住人みんなで使っていた「**みんなの部屋**」。
- 使われなくなって忘れられ、ハザマに落ちて、元カゲの少女「**ミオ**」になった（303＝ミ・オ・サン）。
- 団地の真ん中が抜け落ちたので、街の人の記憶でも団地がぼやけ、「**おぼろ団地**」と呼ばれるようになった。
- フミオの届かなかった手紙は、初代住人のだれかが書いた「**またみんなで集まろう**」という招待状。
- 終章では、今の住人たちが思い出を持ち寄って、303を「みんなの部屋」として **作り直す**。

### 団地の名前
- 正式名は「**灯野第三団地**（ひのだいさんだんち）」、通称は「**おぼろ団地**」。
- 通称の由来：街の人がこの団地を **ぼんやりとしか覚えていない** から付いたあだ名。真ん中の「みんなの部屋」（303）が忘れられて抜け落ちたことが原因。
- 使い分け：書類・回覧板・手紙の宛先は **正式名**、会話とタイトルは **通称**。

## 4. ゲームの流れ（素材を作るための前提）

1. **昼パート（表）＝団地の切り盛り**：プレイヤーは、ハザマで出会った住人を空き部屋に入居させ、部屋を整え、並びを考える。主人公（サカキの孫）も住人の1人として団地に住みこむ。住人がそのまま夜の仲間になる。
2. **夜パート（裏）＝夜回り**：住人の中からパーティを組んでハザマを探索。ランダム生成の階層、宝箱、イベント、カゲとの戦闘。家具や入居希望者もここで見つかる。
3. **章ボス**：各章の最深部に、街の誰かの「大きなワスレモノ」が形になったボスがいる。
4. 数章でエンディング。住人との関係と団地の姿で結末が分岐。

| 3章 | 止まった時計 | →5×5の外枠 | 坂と階段の迷路（坂の上） | シズカ、ユメミ、ヒナコ、ボンボン、トメヨ | 古い市報の図面。303は「みんなの部屋」 |

- 章ボス（ワスレモノ）は倒して終わりではなく、思い出してもらうことで静まる。序章はボスなし（小さなカゲ1体）、1章「最後の大売り出し」、2章「沖に出たままの船」、3章「閉館の日の図書館」、4章カゲモリ、終章「だれにも開けられなかった部屋」（住人全員の総力戦）。各章の終わりに切ない話が1つある。くわしくは 20_story.md。
- **サカキが姿を消した理由**：303を取り戻すために一人でハザマへ通い続け、ある夜、帰れなくなった。日誌の最後に「みんなを呼び戻すまで帰らない」。
- **クリア後**（くわしくは 20_story.md の6章と ideas_postgame.md）
  - **本筋：灯野第一団地・第二団地**。取り壊されて忘れられた2つの団地が、まるごとハザマに沈んでいる。第二→第一の順に、その住人を迎えに行く。中は5×5の部屋割りで、最深部にはその団地の最後の管理人のワスレモノがいる。迎えた住人は入居希望に来るので、住人は30人＋主人公より増える（控えが増える）。
  - **毎日のやりこみ：まどろみ団地**。第三団地が明け方に見る夢。明け方（4〜5時）だけ開き、入るたびに間取りが変わる。深いほど高い★が出やすく、毎回「その夜だけのルール」がある。
- **エンディング**：303に持ち寄った思い出（住人）の数で3つに分かれる。
  - **みんなの部屋**（真）／**ただいま**（通常）／**またいつか**（ほろ苦）
  - さらに住人ごとのエピローグが付く。

## 4-2. 団地システム

### マス目
- 団地は「階×号室」のマス目。最初は **2階×2部屋＝4部屋** だけが使える。章をクリアすると外枠が開く（1章で3×3、2〜3章で4×4、4章で5×5）。
- ほかの部屋が使えない理由は **老朽化**（雨漏り、床が抜けている、配管がだめ）。開いた外枠の部屋は、素材を集めて **1部屋ずつ修繕** する。直した部屋は **格1〜5** まで上げられ、直し終わると窓に明かりがともる。
- 号室番号は「階＋部屋番号」。例：201は2階の1号室。
- **303号室は「ドアだけの部屋」**（物語の軸）。団地は左下（101）から広がり、3×3にした時点から303のマスは「ドアだけの部屋」として表示される（老朽化とは別の見た目）。使える部屋は 3×3＝8部屋、4×4＝15部屋、5×5＝24部屋。24部屋の修繕が終わると303が25番目の部屋として現れる。
  - 303に部屋がないあいだ、303を通る列はそろわない。3×3では3階の横列・3号室の縦列・斜め（101-202-303）。5×5では3階の横列・3号室の縦列・斜め2本の4本（12本中8本が使える）。
  - れんけい・超れんけいの「全部屋」は、終章までは303を除いた部屋数。
  - **ゾロ目の部屋**（階と号室が同じ。101・202・303…の斜め）のうち、303だけは終章まで使えない。

### こせい と 系統（ならびボーナス＝なかよし）

**こせい** は住人の性質。18種類あり、似たものどうしが6つの **系統**（色の名前）にまとまる。

| 系統 | 方向 | こせい | れんけい名（例） |
|---|---|---|---|
| **赤** | 攻撃 | 料理好き／食いしん坊／甘党 | まんぷく：全員の攻撃が大きく上がる |
| **青** | 受けるダメージの軽減・かばう（能力配分 HP1.3・防御1.4・攻撃0.8・素早さ0.7） | 頑固／心配性／力持ち | いしあたま：被ダメージ大幅減 |
| **緑** | 回復・支援（HP1.5倍） | 世話好き／お人よし／おしゃべり | おせっかい：毎ターン回復 |
| **黄** | 素早さ・先制 | 夜ふかし／せっかち／きまぐれ | まよなか：必ず先制 |
| **白** | 探索・ドロップ | 物知り／集め好き／きちょうめん | ものしり：高レア度が出やすい |
| **紫** | 状態異常・裏技 | ひねくれ／さみしがり／なまけもの | うらがえし：敵の能力を奪う |

系統の色（ドット絵）：赤 #F27D52／青 #3F7FA6／緑 #4E8C4A／黄 #FFC857／白 #E8D6C0／紫 #7A5FB8。
系統は住人の札（アイコンの内側）の色で、レア度は外側の光で表す（どちらも色なので混ざらないように分ける）。

#### こせい枠（レベルで開く）
- 住人は最初、**固定のこせいを1つ** 持つ（そのキャラらしさ）。元カゲの住人も同じ。
- レベルが上がると **こせい枠** が開き、中身がランダムで決まる（枠2＝Lv10、枠3＝Lv25、枠4＝Lv40）。
- ランダムで出るこせいは、固定こせいと **同じ系統が出やすい**（同じ系統のほか2つが70%、別の系統が30%）。別の系統が出ると「意外な一面」になる。
- ランダムで開いた枠は「**うらがえし札**」（ハザマで拾う）やヒノカケラで振り直せる。固定こせいは変わらない。
- 最大枠数はキャラごとに違う。とがったキャラは1枠、ふつうは2〜3枠、器用なキャラは4枠。

#### なかよし と れんけい
同じこせい・同じ系統の住人を **横（同じ階）・縦（同じ部屋番号）・斜め** に、その時点の一辺の人数ぶんそろえる。

| 並び | 効果 |
|---|---|
| 同じ **こせい** が一列 | なかよし（大）：+12%（列の長さに比例） |
| 同じ **系統** が一列（こせいはバラバラでよい） | なかよし（小）：+6%（列の長さに比例） |
| 全部屋が同じ **系統** | れんけい（系統ごとの大技。効果は部屋数÷24に比例） |
| 全部屋が同じ **こせい** | 超れんけい（れんけいの1.5倍。やりこみ要素） |

- ライン数が多いほど強くなる。団地が大きいほどれんけいは難しいが効果も大きい。
- れんけいは強いが、苦手な敵が出る階層ではバランス型が有利、という選び方になる。

### 出身地 と じもとボーナス
住人には灯野市の **出身地** が1つある（元カゲは「なくされた場所」が出身地）。こせいとは別の軸。

| 出身地 | ハザマで有利な階層 |
|---|---|
| 商店街 | シャッター街の階層 |
| 港町 | 水びたしの倉庫街の階層 |
| 坂の上 | 坂と階段の迷路の階層 |
| 団地育ち | 団地を裏返した階層 |
| よそ者 | どこでも少しだけ有利 |
| ハザマ生まれ | 最深部の階層 |

- **じもと**：出撃メンバー本人の部屋のまわりに、同じ出身地の隣人が1人いるごとに +3%（1人につき最大 +12%）。
- 出身地と、その夜の階層が合うと +8%。
- 夜回りでどの階層へ行くかで、出撃メンバーを選ぶ理由になる。

### パーティ編成（夜回りのメンバー）
- 出撃メンバーは団地のどの部屋からでも自由に選べる。人数の上限は、開いた段階の団地の一辺（2→5人）。
- **主人公は毎晩かならず出撃する**（31人目の住人）。主人公だけはいつでも自由に引っ越せる。
- ボーナスは2層。
  1. **団地全体のパズルボーナス**（常に効く）：なかよし、れんけい、当たり部屋など、団地全体の並びで決まる。
  2. **出撃メンバーの位置ボーナス**（その夜だけ）：
     - 選んだメンバーが縦・横・斜めに **一直線につながるほど大きくなる** ボーナス「**ひとすじ**」：2人+2%／3人+4%／4人+7%／5人+10%
     - 選んだメンバーのうち **2人が隣り合うごとに付く小さい** ボーナス「**おとなり**」：上下左右に隣り合う1組ごとに+1%
- ボーナスはすべて％の足し算。上限は **全能力にかかるボーナスの合計で+25%**、**1つの能力値の合計で+80%**。れんけいは上限の外。
- くわしい数値と根拠は [../system/balance_sim.md](../system/balance_sim.md)（戦闘シミュレーションの調整案2）。
- 一直線を狙うか、隣り合う組を数で稼ぐか、位置を無視して強い住人を選ぶかでバランスを取る。
- 出撃しなかった住人は **留守番** として、系統に応じたサポートをする（1人あたり 赤＝攻撃+2%、青＝防御+2%、緑＝戦闘のあと全員のHP+3%、黄＝不意打ち−5%、白＝ひろいもの+3%、紫＝状態異常+3%。同じ系統は3人まで）。ボスにはほとんど効かず、1夜に戦える回数を延ばす。**★1の住人は留守番の効果が2倍**。
- アイテムと作戦の指示はプレイヤーが行う（画面に管理人役のキャラは出ない）。
- 住人は本編で約30人（5×5の25部屋＋控え）。クリア後に第一・第二団地の住人が加わって増える。

### 戦闘
- **行動順タイムライン制**：素早さで行動の順番が決まり、画面上に次に動く順番が並ぶ。
- **作戦**：雑魚戦はオートで、プレイヤーは「作戦」（攻める・守る・回復優先など）を選ぶ。ボス戦は手動で指示する。
- **カゲにも系統がある**。苦手な系統から受けるダメージは ×1.3、得意な系統から受けるダメージは ×0.7。
- **難易度**：ドラクエくらい（簡単すぎない）。推奨レベルでボスの勝率は6割前後、雑魚1戦でHPが15%ほど減る。
- **わざの回数**：1夜で共有し、戦闘ごとには戻らない。固有わざは1夜に3回。レベルアップで覚えるわざは「光」（ヒノカケラの光。MPのかわり）を使い、1夜に6回まで。
- **救済策**：①「おすすめの並び」ボタン：出撃メンバーを一列にして、出身地と階層を合わせる並びを1回で提案する。②**管理人室で休む**：夜回りの途中で境目から団地に戻ると全回復できる（ドラクエの宿屋にあたる）。
- くわしい数値は ideas_system.md と ../system/skills_numbers.md。

### 部屋の条件（レア住人の採用）
住人ごとに「住みたい条件」がある。部屋は次の4つで評価される。

1. **部屋の性能**：日当たり、静かさ、広さ（1〜5。修繕で上がる）
2. **号室番号の効果**：**ゾロ目の部屋**（階と号室が同じ。101・202・404・505＝斜めのライン）、角部屋、最上階など。さらに月ごとに「**当たり部屋**」がランダムで抽選される。
3. **置いてある家具**：家具の種類・レア度・セット
4. **となり**：となりの部屋に特定の住人がいる／いない（例：「ゲンゾウのとなりはいやだ」）

- 例：★5の住人「トメヨ」の条件＝最上階・日当たり3以上・★5以上の窓辺家具がある部屋。
- 条件の数の目安：★1＝なし、★2＝1つ、★3＝2つ、★4＝3つ、★5＝3つ＋物語、★6＝物語の終盤。303は入居条件に使わない。
- 序盤は条件のゆるい住人しか来ない。後半、修繕と家具で条件を満たせると、レア住人を採用できる。
- 入居希望者は「**内見**」に来る。条件は内見で一部だけ分かり、★4以上は残りをハザマで手がかりとして探す。

### 家具（ひろいもの）
- ハザマで拾う。レア度（4-3）とランダムな「ことば」が付く。
- 部屋の性能を上げる／特定の住人の好みを満たす／同じシリーズをそろえるとセット効果。

1. 背景のマゼンタ #FF00FF を透過にする
2. 目標サイズに **ニアレストネイバーで縮小**（例：キャラは24×32）
3. 5-3のパレットに **減色**
4. Asepriteなどで目・輪郭の1pxを手直し

ImageMagickでの例（palette.png は5-3の色を並べた画像）：
```
magick input.png -filter point -resize 24x32 +dither -remap palette.png output.png
```
