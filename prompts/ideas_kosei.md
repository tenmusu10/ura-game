# こせい拡張・元カゲのランダムこせい・出身地（たたき台）

> 検討の経過です（古い案や取り消した案も含みます）。決定内容は 00_world_bible.md を見てください。

tenmusuさんの3つの要望を、ひとつのしくみにまとめた案です。

---

## 1. こせいを18種類に増やし、6つの「系統」に分ける

似たこせいを同じ系統にまとめる。系統ごとに戦闘での方向性が決まる。

| 系統 | 方向 | こせい（3つずつ） |
|---|---|---|
| **食**（しょく） | 攻撃 | 料理好き／食いしん坊／甘党 |
| **守**（まもり） | 防御 | 頑固／心配性／力持ち |
| **和**（なごみ） | 回復・支援 | 世話好き／お人よし／おしゃべり |
| **夜**（よる） | 素早さ・先制 | 夜ふかし／せっかち／きまぐれ |
| **知**（ち） | 探索・ドロップ | 物知り／集め好き／きちょうめん |
| **影**（かげ） | 状態異常・裏技 | ひねくれ／さみしがり／なまけもの |

- 「元カゲ」はこせいから外し、**種別**（人・元カゲ・動物など）にする。
- 系統名は仮。

### なかよし・れんけいの数え方
| 並び | 効果 |
|---|---|
| 同じ **こせい** が一列にそろう | なかよし（大） |
| 同じ **系統** が一列にそろう（こせいはバラバラでもOK） | なかよし（小） |
| 全部屋が同じ **系統** | れんけい（系統ごとの大技。「まんぷく」「いしあたま」など） |
| 全部屋が同じ **こせい** | 超れんけい（ほぼ不可能なやりこみ要素） |

こせいが18種類に増えても、系統でそろえれば狙いやすいので、パズルが難しくなりすぎない。

## 2. 元カゲのこせいはランダム、あとから変更できる

- 元カゲの住人は、入居したときにこせいが **ランダムで決まる**。レア度が高いほど、こせいの数が多くなりやすい。
- 人間の住人のこせいは固定（キャラの性格そのもの）。
- 元カゲのこせいは、あとから **ランダムで振り直せる**。
  - 振り直しの方法（案）：ハザマで拾う「**うらがえし札**」を使う／ヒノカケラを払う
  - 1つだけ振り直す・全部振り直す・1つだけ残して振り直す、のように段階を付ける
- 同じ元カゲでも、プレイヤーごとにこせいが違う。「理想のこせいの元カゲ」を狙うやりこみになる。

---

## 2-B. 別案：レベルで「こせい枠」が開き、中身はランダム（tenmusuさん案）

- 住人は最初 **1つだけ固定のこせい**（そのキャラらしさ）を持つ。元カゲは最初の1つもランダム。
- レベルが上がると **こせい枠** が開き、開いた瞬間に中身がランダムで決まる（例：Lv10・Lv25・Lv40）。
- 枠の最大数はキャラごとに決める。とがったキャラは最大1〜2枠、器用なキャラは最大4枠など。
- ランダムの出方は、そのキャラの固定こせいと **同じ系統が出やすい**（キャラらしさを保つ）。まれに別系統が出て「意外な一面」になる。
- ランダムで開いた枠だけ、「うらがえし札」であとから振り直せる。固定の1つは変わらない。
- 演出：枠が開くときにレア度の色で光る（こせいにもレア度を付ける案もあり）。

**こちらの良いところ**
- 育てるほどパズルの選択肢が増え、「次の枠で何が出るか」のワクワクが続く。
- 序盤はこせいが少ないので、2×2の小さな団地でも並べ方を覚えやすい。
- 人間の住人の性格（固定こせい）を壊さずにランダム性を足せる。

## 3. 出身地（もう一つの軸）

住人それぞれに灯野市の **出身地** を1つ付ける。こせいとは別のボーナス。

| 出身地 | 例 | ハザマで有利な階層 |
|---|---|---|
| 商店街 | ユズコ、ハルナ、チヨノ | シャッター街の階層 |
| 港町 | ミナト、タツゾウ、ルスオ | 水びたしの倉庫街の階層 |
| 坂の上（山手） | シズカ、ユメミ | 坂と階段の迷路の階層 |
| 団地育ち | トメヨ、サキミキ、サカキ | 団地を裏返した階層 |
| よそ者 | リョウ、ゴウダ | どこでも少しだけ有利 |
| ハザマ生まれ | 元カゲの住人 | 最深部の階層 |

- **同郷**（どうきょう）ボーナス（仮）：同じ出身地の住人が隣り合う、または一列にそろうと、小さいボーナス。
- ハザマの階層は「街の一角を裏返した見た目」（バイブル）なので、出身地が合う階層では有利になる。夜回りの前に「今夜はどの階層へ行くか」で出撃メンバーを選ぶ理由ができる。
- 出身地が同じ住人どうしの会話イベントも作りやすい。
