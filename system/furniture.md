# 家具（ひろいもの）とセット効果、留守番の数値

2026-10-31。戦闘のバランス（balance_sim.md 第3版）と成長・経済（economy.md）の続きです。家具と留守番が戦闘に効く大きさは、シミュレータ（`system/sim/rusuban.py`・`typical.py`）で確かめました。

## 結論（先に）

1. **留守番は、ボス戦にはほとんど効かず、夜回りの長さに効きます。** 赤・青・緑を3人ずつ（最大）そろえても、ボスへの戦力は約+3%です。一方、緑の留守番3人（戦闘のあとに全員のHPを9%回復）で、1夜に戦える回数が約1.4倍（3章：5.7→7.9戦）になります。今の数値のままで問題ありません。
2. **家具で全能力を上げると、効きすぎます。** 住人1人に「全能力+10%」を配ると、5章で1夜に戦える回数が2倍（10→20戦）になります。家具は **1つの能力だけ** を上げ、**住人1人の家具の合計は+10%まで** にします。
3. **★1の住人は留守番の効果を2倍に** します。★1の緑（カタッポ）1人が、緑の留守番2人分になります（緑3人分を2倍にすると、5章で1夜10→14戦）。「ネタ枠が留守番で輝く」狙いどおりで、ボスへの戦力はほとんど変わりません。
4. **第3版のボスは、家具と留守番を入れると少し楽になります。** ふつうに家具をそろえて留守番もいる状態で、勝率6割になるように、ボスの強さを（下の表の倍率で）上げます。

## 1. 家具の種類

家具は8種類の「置き場所」に分かれます。1部屋に置ける家具は **3つまで**（広さ4以上で4つ）。

| 置き場所 | 上がる部屋の性能 | 住人に効く能力 | 例（住人の入居条件に出てくる家具） |
|---|---|---|---|
| 台所 | 広さ | HP | コンロ、冷蔵庫、ちゃぶ台 |
| 窓辺 | 日当たり | 素早さ | 植木鉢、風鈴、レースのカーテン |
| 寝床 | 静かさ | HP | 二段ベッド、こたつ、ふとん |
| 棚 | 広さ | 防御 | 本棚、飾り棚、ガラスケース |
| 机 | 静かさ | 攻撃 | 机、ミシン台、製図台 |
| 壁 | 日当たり | 防御 | 掲示板、姿見、柱時計 |
| 明かり | 日当たり | 運 | 電気スタンド、ちょうちん、ランタン |
| 思い出 | ― | ― | 父の船の模型など。物語で手に入る1点もの |

## 2. 家具の★と効果

| ★ | 部屋の性能 | 住んでいる住人の能力 | 売ったときのヒノカケラ |
|---|---|---|---|
| ★1 | +0 | +1% | 10 |
| ★2 | +1 | +2% | 30 |
| ★3 | +1 | +3% | 100 |
| ★4 | +2 | +4% | 300 |
| ★5 | +2 | +5% | 1,000 |
| ★6 | +3 | +6% | 売れない |

- 部屋の性能（日当たり・静かさ・広さ）は、修繕の「格」がもとの値で、家具で **格より2まで** 上げられます（最大5）。
- 住人の能力アップは、その部屋に住んでいる住人だけに効きます。**1人の合計は+10%まで**（全能力ボーナスの+25%、1能力の+80%の上限とは別に数える）。
- 拾える家具の★は、4-3の表（★1 45%〜★6 0.5%）。深い階ほど高い★が出やすい。1夜に拾える家具は1〜2個。

## 3. ことば（家具にランダムで0〜2個つく）

| ことば | 効果 |
|---|---|
| ぴかぴかの | 部屋の性能 +1 |
| ちょっと湿った | 静かさ +1、日当たり −1 |
| ひだまりの | 日当たり +1 |
| ふかふかの | 住人のHP +1%（上限の+10%に含む） |
| がっしりした | 住人の防御 +1% |
| かるい | 住人の素早さ +1% |
| なつかしい | 住んでいる住人の経験値 +5% |
| よく光る | 夜回りの「光」+1（その住人が出撃した夜だけ） |
| ねむくなる | 留守番の効果 +50%（その住人が留守番の夜だけ） |
| うるさい | 静かさ −1、となりの部屋の静かさ −1 |
| だれかの大事な | ★5以上だけにつく。持ち主の短い物語が読める（効果なし） |
| 裏返った | ハザマ生まれの住人がその部屋に住むと、部屋の性能 +1 |

## 4. セット（シリーズ）

灯野市のさびれた場所ごとに6シリーズ、各4点。**団地のどこに置いてもよく**、そろえた数で効果が出ます。そのシリーズは、対応する階層でよく拾えます（出身地と同じ6区分）。

| シリーズ | 拾いやすい階層 | 2点そろうと | 4点そろうと |
|---|---|---|---|
| 灯野銀座（商店街） | シャッター街 | その階層のひろいもの +10% | 購買の値段 −20% |
| 港の食堂（港町） | 水びたしの倉庫街 | 同上 | 雑魚戦のあと、全員のHP +3% |
| 坂の上の洋館（坂の上） | 坂と階段の迷路 | 同上 | 「光」が1夜に+1（6→7回） |
| 昭和の茶の間（団地育ち） | 団地を裏返した階層 | 同上 | 留守番の効果 ×1.5 |
| 旅のかばん（よそ者） | どこでも少しずつ | 同上 | 夜回りに持っていけるアイテム +2（8→10個） |
| 裏返しの部屋（ハザマ生まれ） | 最深部 | 同上 | 管理人室で休める回数 +1（1夜に2→3回） |

- セットの効果は、戦闘の強さより **夜回りの長さと準備** に効くものにしました。ボスへの戦力を直接上げると、第3版の難易度がくずれるためです。
- 「港の食堂」の4点は、緑の留守番1人と同じ大きさです（緑3人で約1.4倍なので、1人分はその3分の1くらいの見込み）。

## 5. 留守番（今の数値と、確かめた結果）

| 系統 | 1人あたりの効果（同じ系統は3人まで） | ボスへの戦力（3人） | 1夜の戦闘回数（3人） |
|---|---|---|---|
| 赤 | 出撃メンバーの攻撃 +2% | +2% | ほぼ同じ |
| 青 | 出撃メンバーの防御 +2% | ±0% | ほぼ同じ |
| 緑 | 戦闘のあと、全員のHP +3% | +1% | **約1.4倍**（3章 5.7→7.9戦、5章 10→12戦） |
| 黄 | 不意打ちされる確率 −5% | （計っていない） | |
| 白 | ひろいもの・ヒノカケラ +3% | ― | ― |
| 紫 | 敵に状態異常が入る確率 +3% | （計っていない） | |
| 赤3・青3・緑3（最大） | | +2〜3% | 約1.3〜1.6倍 |

- **★1は留守番の効果2倍**（新ルール）：★1の3人（カサジロウ・カタッポ・ペンタ）が、留守番で役に立つようにします。
- 留守番の経験値は30%のまま（economy.md）。

## 6. 家具と留守番を入れたときのボスの強さ

ふつうに家具をそろえ（住人1人あたり攻撃+4%・HP+4%・防御+3%・素早さ+2%）、留守番に赤・青・緑が2人ずついる状態で計算し直しました。

| 章 | 第3版のボスで勝率（家具なし→あり） | ボスを強くする倍率 | 新しいボス（HP・攻撃・防御。素早さは第3版のまま） |
|---|---|---|---|
| 1章 | 64% → 80% | ×1.07 | HP 296・攻撃 39・防御 29・素早さ 26 |
| 2章 | 57% → 73% | ×1.05 | HP 689・攻撃 60・防御 45・素早さ 35 |
| 3章 | 65% → 84% | ×1.07 | HP 1,445・攻撃 94・防御 71・素早さ 44 |
| 4章 | 58% → 69% | ×1.03 | HP 2,410・攻撃 156・防御 117・素早さ 52 |
| 5章 | 59% → 74% | ×1.04 | HP 4,889・攻撃 254・防御 190・素早さ 62 |
| 終章 | 59% → 67% | ×1.05 | HP 6,563・攻撃 341・防御 256・素早さ 68 |

- ボスを強くする倍率は ×1.03〜1.07 で小さく、家具と留守番は「少し楽になる」くらいの効き方です。
- 雑魚は第3版のまま（家具と留守番で1夜に戦える回数が増えるのは、準備のごほうびとしてそのままにします）。

## 7. 決めてほしいこと

- 家具の能力アップを「1人+10%まで」にする（おすすめ）か、家具は部屋の性能だけにして能力は上げない（もっと簡単）か。
- セットの4点効果を、上の「夜回りの準備に効くもの」にする（おすすめ）か、戦闘の強さに効くものにするか。
